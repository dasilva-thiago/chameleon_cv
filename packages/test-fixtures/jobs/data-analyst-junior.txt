Analista de Dados Júnior

Empresa: Instituto Mapa Social (organização sem fins lucrativos)
Local: remoto, Brasil

Buscamos uma pessoa para transformar dados de programas educacionais em indicadores para gestores públicos.

Responsabilidades
- Consultar bases com SQL e preparar dados para análise.
- Construir painéis e relatórios claros para públicos não técnicos.
- Documentar métodos e premissas das análises.

Requisitos
- SQL intermediário.
- Python (pandas) ou R para análise de dados.
- Excel avançado.
- Boa comunicação escrita e oral.

Desejável
- Power BI ou ferramenta similar.
- Experiência com dados educacionais ou do setor público.

Não exigimos experiência anterior na área de dados; avaliamos projetos e trajetória.
